## 📖 Sobre o projeto

Este portfólio foi desenvolvido como avaliação final da disciplina de Front End do primeiro semestre do curso de Análise e Desenvolvimento de Sistemas (ADS), no Centro Universitário UDF.

O objetivo do projeto é apresentar minha trajetória acadêmica, meus conhecimentos em desenvolvimento de software e os principais trabalhos realizados durante o primeiro semestre da graduação.

O site foi desenvolvido utilizando HTML, CSS e JavaScript, com foco em responsividade, acessibilidade, organização de código e experiência do usuário.

## 🎨 Design e interface

O portfólio apresenta uma identidade visual minimalista, utilizando tons de laranja como destaque, com suporte aos modos claro e escuro.

As fontes utilizadas são:

- Bricolage Grotesque.
- DM Sans.

A interface foi desenvolvida com CSS Grid, Flexbox, variáveis CSS e Media Queries, permitindo sua adaptação a diferentes tamanhos de tela.

## ⚙️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o projeto localmente.

O portfólio não necessita de instalação de dependências ou configuração de um servidor backend.

## 🌐 Hospedagem no GitHub Pages

Para publicar o projeto:

1. Acesse as configurações do repositório (Settings).
2. Selecione a opção Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione a branch main.
5. Selecione a pasta /(root).
6. Clique em Save.

Após a publicação, o GitHub disponibilizará o endereço de acesso ao portfólio.
